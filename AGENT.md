## Архитектура — кратко

### Физика (`cloth.h`, `cloth.cpp`)
- Verlet integration, 8 сабстепов на кадр (`NUM_SUBSTEPS=8`), `dt_sub = 1/(60*8)`
- Сетка `cols × rows` (runtime, не constexpr), по умолчанию 40×40
- Верхний ряд (`row=0`) — закреплён (`pinned=true`)
- Три типа constraints: structural (соседи), shear (диагонали), bend (через одного)
- 8 итераций солвера на сабстеп = 64 итерации на кадр
- `damping` и `wind_strength` — runtime-переменные, задаются снаружи через `heaviness`

### Взаимодействие (`interaction.h`, `interaction.cpp`)
- Захват одной ближайшей к лучу частицы (`grabbed_idx`)
- Во время drag: частица временно `pinned=true` в main.cpp (constraints распространяются от неё)
- Скорость мыши передаётся через `prev_position = prev_target` — при отпускании частица летит в направлении движения мыши
- `RAY_THRESHOLD = 0.18f` — порог расстояния луч→частица для захвата

### Рендерер (`renderer.h`, `renderer.cpp`)
- `STB_IMAGE_IMPLEMENTATION` определён **только** в renderer.cpp
- `stbi_set_flip_vertically_on_load` — **выключен** намеренно: UV row 0 = верх изображения = верх ткани
- Индексный буфер пересобирается автоматически при смене размера сетки (проверка по `expected = (cols-1)*(rows-1)*6`)
- `reload_texture(path)` — смена текстуры без пересоздания шейдеров и VAO
- `image_size(path, w, h)` — static метод, читает размер через `stbi_info` без загрузки в GPU

### Загрузка изображения (`main.cpp`: `apply_image`)
- Drag & Drop на окно → `SDL_DROPFILE` event
- `grid_from_aspect(aspect, cols, rows)`: целевой размер ~1600 частиц
  - `cols = round(sqrt(1600 * aspect))`, `rows = round(sqrt(1600 / aspect))`
- После смены сетки камера перецентрируется на середину ткани
- Сетка пересчитывается и при запуске с аргументом `./cloth_sim image.png`

### Heaviness (`main.cpp`: `apply_heaviness`)
- Диапазон 0.0–1.0, шаг 0.1 клавишами `[`/`]`
- **Экспоненциальная шкала** (линейное восприятие на всём диапазоне):
  ```cpp
  float log_min = log(0.9999f);  // почти нет трения
  float log_max = log(0.9940f);  // максимальное трение
  cloth.damping = exp(log_min + h * (log_max - log_min));
  ```
- **ВАЖНО**: damping — коэффициент СОХРАНЕНИЯ скорости (меньше = больше трения = тяжелее)
  - Это контринтуитивно: `heaviness↑ → damping↓`
- `wind_strength = 0.15 * (1-h)²` — ветер убывает квадратично с тяжестью
- Текущее значение видно в заголовке окна

## Известные нюансы (пользователь отложил)

1. **Мелкие физические артефакты** — пользователь сказал "есть нюансы но потом доделаем". Конкретика не уточнялась, возможно:
   - Небольшое растяжение в углах при резком рывке
   - Анимация слегка дёргается при очень высоком heaviness (почти нет движения → constraint oscillation становится заметна)

2. **Камера** — простая orbit-камера без инерции. Может захотеть сглаживание.

3. **Нет HUD** — heaviness показывается только в заголовке окна. Возможно, захочет на экране.

4. **Нет сохранения настроек** — heaviness сбрасывается при перезапуске.

5. **Grab radius** — сейчас захватывается одна точка. Пользователь не просил менять, но при очень крупной сетке может быть некомфортно.

## Что НЕ делать

- **Не трогать** `stbi_set_flip_vertically_on_load` — было намеренно убрано, изображение правильно ориентировано
- **Не добавлять CUDA / PhysX** — явное требование из AGENTS.md, CPU-only
- **Не добавлять ImGui или другие UI-библиотеки** без запроса — пользователь предпочитает простое решение (заголовок окна)
- **Не менять** `NUM_SUBSTEPS` и `CONSTRAINT_ITERS` без понимания: текущие 8×8=64 итерации — результат тюнинга
